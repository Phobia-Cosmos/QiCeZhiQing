# 企策智擎——企业经营沙盘决策智能体

企策智擎面向企业经营沙盘中的单个参赛企业，在部分可观测条件下提供状态问答、风险档位建议、联合经营方案、订单履约规划和赛后复盘。系统把资金、资格、产能、供应、订单与风险放入同一决策流程，Agent 负责组织与解释建议，独立模拟环境负责订单分配、财务结算、违约和破产判定。

云端页面可以创建模拟比赛、查看赛前规则、向 Agent 提问、提交经营与申领方案、观察系统自动订单分配、查看我方实际获单并继续履约。云端使用腾讯 CloudBase HTTP 云函数兼容运行层和模拟数据；会话保存在函数实例内，实例重启后需要重新创建比赛。

## 核心闭环

1. 读取本企业现金、权益、负债、资格、资产、库存、订单和当前公开信息。
2. 由资金、资格、产能、供应履约、订单组合和风险模块形成联合建议。
3. 用户可以继续询问、修改动作并决定是否提交。
4. 模拟环境统一执行订单分配、交付、财务结算、违约和破产判定。
5. 系统生成季度反馈、人机方案差异、年度报表和终局复盘。

## 当前验证结果

- 完整私有版本通过 `110` 条自动化测试。
- 支持 5 年、20 季度的双阶段决策闭环。
- 每场可生成约 800 条模拟订单。
- Demo 包含 13 个操作场景、同步普通话旁白和终局排名。
- 腾讯云公网验收已完成“创建比赛 → Agent 问答 → 提交方案 → 自动分配 → 查看我方获单”。

详细机器可读摘要见 [validation_summary.json](results/validation_summary.json)。

## 公开边界

本仓库是无内部 Git 历史的脱敏成果仓库，不包含完整源码、原始比赛文件、历史逐企业轨迹、规则提取数据、内部订单模板、Agent 阈值、访问令牌或可直接复现全部策略的参数。视频、截图和在线比赛均使用模拟规则、模拟订单及虚构企业名称。

当前源码仓库保持私有。公开材料用于说明产品工作量、系统闭环、专业性和创新点，不承诺在任意真实比赛与任意对手组合下取得固定名次。
