# StratPilot — Enterprise Decision Agent

StratPilot 是面向企业经营沙盘中单个参赛企业的可审计人机协同决策系统。在部分可观测条件下，系统读取本企业状态、公开订单和比赛规则，由资金、资格、产能、供应履约、订单组合与风险模块联合形成建议；独立模拟环境负责订单分配、财务结算、违约、破产和终局排名。

## 当前核心闭环

1. 读取本企业现金、权益、负债、资格、资产、库存、订单和当前公开信息。
2. 资金、资格、产能、供应履约、订单组合和风险模块形成稳健、平衡或增长方案。
3. 用户可以询问当前状态、修改动作并决定是否提交。
4. 每季度只提交一次联合动作包，模拟环境随后统一执行订单竞争、交付和财务结算。
5. 系统记录季度反馈、人机方案差异、年度报表和终局轨迹，用于复盘与离线验收。

## LLM 边界

当前版本没有接入任何 LLM，也没有指定 OpenAI、DeepSeek、Qwen、Claude 或其他模型。状态问答、风险档位、动作生成和解释均来自可审计的确定性代码与启发式策略。“多 Agent”表示一个企业内部的六个专业决策模块，并不表示六个大模型。

未来可以把 LLM 接在自然语言理解、规则检索和解释组织层，但现金、库存、合法性、破产与得分必须继续由确定性状态机计算。

## 当前验证结果

- 私有正式版本通过 116 项自动化测试，失败 0 项。
- 支持 5 年、20 季度、每季度单次提交的完整比赛。
- 每场生成约 800 条模拟全局订单。
- 默认六企业校准场中，各企业通常获得约 13–21 单；排名由环境实际结算，不保证 Agent 第一。
- 支持导出与比赛资料相近的 XLSX 数据包，包括逐企业资产、研发时间、贷款时间、现金流备注、年度报表、全局订单、规则和终局结果。
- 本地浏览器验收已覆盖 800 条赛前全局订单、Agent 三套方案、单次提交、五年托管和终局导出。

详细机器可读摘要见 [validation_summary.json](results/validation_summary.json)。

## 公开边界

本仓库是与私有源码仓库隔离的脱敏成果仓库，不包含完整源码、原始比赛文件、历史逐企业轨迹、规则提取数据、内部订单模板、Agent 阈值、账号、访问令牌或可直接复现核心策略的参数。视频、截图和在线比赛使用模拟规则、模拟订单及虚构企业名称。

公开材料用于说明产品闭环、工作量和专业性，不承诺在任意真实比赛、任意规则或任意对手组合下取得固定名次。最新源码仓库保持私有。
