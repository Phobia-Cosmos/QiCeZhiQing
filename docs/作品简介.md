# 作品简介

StratPilot 是一套面向企业经营沙盘的单企业人机协同决策系统。比赛中，订单、采购、生产能力、库存、研发、融资和现金预算彼此制约，而参赛者往往只能观察本企业状态、当前公开订单及规则允许的信息，容易出现订单承诺超过产能、资金链断裂和决策难以复盘等问题。

系统将比赛规则、本企业私有状态和当前公开信息组织为统一观察，由资金、资格、产能、供应履约、订单组合和风险模块协同形成稳健、平衡或增长方案，并给出可读理由、参考公式和禁忌操作。用户可向 Agent 询问当前状态、修改动作，再以一个联合动作包完成本季度提交；订单竞争、财务结算、违约、破产和报表由独立模拟环境统一判定，Agent 的预期不能直接改变结果。系统同时记录季度反馈、人机方案差异和终局轨迹，用于赛后复盘与 VPD 验收。

项目创新在于把部分可观测决策、确定性财务状态机、多专业 Agent 协作、反事实接口和可审计解释连成一个闭环，使系统既能辅助真实参赛者，也能在本地生成多种对手和订单场景进行鲁棒性测试。当前版本没有接入 LLM；自然语言状态问答和动作建议来自确定性工具，未来的 LLM 也只作为理解与解释层，不负责财务真值。
