# 系统架构与公开边界

StratPilot 由三个解耦部分组成：单企业决策智能体读取我方状态并生成建议；模拟器作为独立裁判执行订单分配和完整财务状态转移；评估模块读取动作、反馈和终局轨迹，生成人机差异、季度复盘、报表和验收指标。

腾讯云地址部署的是 2026-08-14 发布的 v0.1 比赛应用兼容层，可以完成创建比赛、状态问答、旧版双阶段提交、订单分配、获单查看和季度结算。由于当前 CloudBase 体验环境未开通容器云托管，云端采用 Node.js HTTP 云函数维持模拟会话；它不是当前私有正式内核。正式内核已经改为“年度大规划 + 每季度一次动作包提交 + 结算反馈后滚动修订”，完整 Python 状态机、历史数据处理、规则反推和大规模实验仍保留在私有环境。

当前决策系统没有接入 LLM。六个专业 Agent 是资金、资格、产能、供应履约、订单组合和风险六类确定性模块；它们读取本企业私有状态、公开订单和规则允许的信息，最终动作必须由状态机预演和校验。未来 LLM 只能承担自然语言理解、规则检索和解释组织，不能直接修改现金、库存、报表、破产状态或终局得分。

公开仓库只保留成果材料与模拟数据界面，不包含原始比赛数据、完整规则参数范围、逐企业历史轨迹、完整源码、策略阈值、账号和访问凭据。公开 Demo 的企业、规则和订单均为模拟内容。视频、截图、PPT 和云端页面保留 v0.1 历史状态，不应被理解为当前正式内核的逐像素展示。
