# 系统架构与公开边界

企策智擎由三个解耦部分组成：单企业决策智能体读取我方状态并生成建议；模拟器作为独立裁判执行订单分配和完整财务状态转移；评估模块读取动作、反馈和终局轨迹，生成人机差异、季度复盘、报表和验收指标。

腾讯云地址部署的是比赛应用公开演示兼容层，可以实际完成创建比赛、状态问答、两阶段提交、订单分配、获单查看和季度结算。由于当前 CloudBase 体验环境未开通容器云托管，云端采用 Node.js HTTP 云函数维持模拟会话；完整 Python 状态机、历史数据处理、规则反推和大规模实验仍保留在私有环境。

公开仓库只保留成果材料与模拟数据界面，不包含原始比赛数据、完整规则参数范围、逐企业历史轨迹、完整源码、策略阈值和访问凭据。公开 Demo 的企业、规则和订单均为模拟内容。
